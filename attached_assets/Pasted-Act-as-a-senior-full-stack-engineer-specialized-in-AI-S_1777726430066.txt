## 🎯 Project Goal

AutoSub is a web application that:

* Uploads video/audio files
* Extracts audio using FFmpeg
* Transcribes speech to text using **faster-whisper (local model, NOT OpenAI API)**
* Translates subtitles using a FREE solution (MyMemory or LibreTranslate)
* Generates SRT subtitle files
* Allows preview and download

---

## ⚠️ VERY IMPORTANT RULES

* DO NOT use OpenAI Whisper API or GPT
